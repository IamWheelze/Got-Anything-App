# 📅 The "Got This Thing" Scheduler

> Never be free when you don't want to be!

An app that automatically populates your calendar with plausible-sounding, fake obligations whenever a person you want to avoid asks, "What are you doing next Tuesday?"

## 🎭 What Is This?

The Got This Thing Scheduler is a hilariously practical web application that generates convincing fake calendar events to help you politely decline unwanted social commitments. Simply click a button and your calendar fills up with believable excuses ranging from dentist appointments to family obligations to that vague "thing I committed to ages ago."

## ✨ Features

- **🎲 Smart Excuse Generator**: Automatically creates 10-25 plausible fake obligations spanning the next 60 days
- **📆 Interactive Calendar**: Visual month-by-month calendar showing all your "commitments"
- **🔍 Quick Lookup**: Enter any date to instantly get your excuse for that day
- **🎨 Category-Coded Events**: Events are color-coded by type (medical, family, work, home, personal, social, vague)
- **💾 Persistent Storage**: Your fake obligations are saved locally and persist across sessions
- **📱 Responsive Design**: Works beautifully on desktop, tablet, and mobile devices
- **🎯 Personalization**: Optionally add the person's name for a more personalized excuse

## 🚀 Getting Started

### Installation

No installation required! This is a pure client-side application.

1. Clone or download this repository
2. Open `index.html` in any modern web browser
3. Start generating excuses!

### Usage

1. **Generate Obligations**: Click the "Generate Fake Obligations" button to populate your calendar with random events
2. **Check Your Schedule**:
   - Click on any calendar day to see what you're "doing" that day
   - Use the Quick Excuse Finder to query a specific date
3. **Get Your Excuse**: Enter a date and optionally the name of the person asking, then click "What am I doing?" for a formatted response
4. **Navigate**: Use the arrow buttons to browse different months
5. **Clear Calendar**: If needed, use the "Clear Calendar" button to start fresh

## 🎪 Excuse Categories

The app generates excuses across seven believable categories:

- **Medical** 🏥: Dentist appointments, checkups, therapy sessions
- **Family** 👨‍👩‍👧: Family dinners, helping parents, babysitting
- **Work** 💼: Meetings, deadlines, presentations, reviews
- **Home** 🏠: Plumber visits, inspections, repairs
- **Personal** 📚: Classes, volunteering, car maintenance
- **Social** 🎉: Birthday parties, weddings, concerts
- **Vague** 🤷: "That thing I can't get out of", "prior commitment"
